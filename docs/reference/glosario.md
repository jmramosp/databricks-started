# Glosario

**Lakehouse:** arquitectura que combina flexibilidad de data lake con operaciones y gobierno de datos tabulares.

**Spark:** motor distribuido de procesamiento.

**DataFrame:** colección de datos estructurados y distribuida con esquema.

**Lazy evaluation:** planificación diferida de transformaciones hasta que se ejecuta una acción.

**Shuffle:** redistribución de datos entre particiones, potencialmente costosa.

**Delta Lake:** formato de tablas con transacciones y registro de cambios.

**Unity Catalog:** gobierno y organización de objetos y permisos.

**Bronze:** fuente conservada; **Silver:** datos validados; **Gold:** datos modelados para consumo.

**CDC:** captura de cambios en datos fuente.

**SCD2:** conservación de históricos de atributos dimensionales.

**Checkpoint:** estado persistente que facilita recuperación del streaming.

**Idempotencia:** ejecutar de nuevo una carga sin generar resultados incorrectos o duplicados.
