# Contribución y aprendizaje

1. Abre una rama `feature/<tema>` para ejercicios o ampliaciones.
2. Mantén Markdown legible y ejemplos reproducibles.
3. Nombra código Python en `snake_case`; añade tests a transformaciones.
4. No publiques credenciales, identificadores personales ni datos sensibles.
5. Explica el cambio en el pull request y relaciona la evidencia de pruebas.

Este material es educativo e independiente; contrasta diferencias de versión y Free Edition con la documentación oficial.
